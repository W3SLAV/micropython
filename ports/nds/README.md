The Nintendo DS port
=================

This port is a modified copy of the bare-arm port and is very minimal, but functional. The output should be named firmware.nds and located in the build folder.

All rights go their respective owners. The nds_9 linker is from calico, and was only copied to this location to make minor changes without messing with the devkitPro install, it is liscened under ZPL, the ZPL notice has been added to the linker to reflect this.
